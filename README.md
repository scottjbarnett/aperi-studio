# Aperi Studio v0.1

A simple static starter site for aperi.studio.

## Files

- `index.html`
- `style.css`
- `assets/aperi-studio-mark.svg`

## GitHub Pages setup

1. Create a new public repo, e.g. `aperi-studio`.
2. Upload these files.
3. Go to Settings > Pages.
4. Set Source to "Deploy from a branch".
5. Select `main` and `/root`.
6. Add the custom domain `aperi.studio`.
7. Add the GitHub Pages DNS records in Porkbun.
8. Enforce HTTPS once GitHub allows it.

## Notes

This is intentionally static and lightweight. It can later be converted into Jekyll, Astro, or a richer project library.
